何が起きていたか
----------------------------------------------------------

「代表の表記を、最後の入力ではなく使用状況から選ぶ」という直しをしたとき、
依頼を積むコードから name を書かないようにしました。

  コード:  setDoc(親, { key, updatedAt })        ← name を書かない
  ルール:  name is string && name.size() > 0     ← name を必須のまま

name が無いのでルールが拒否し、依頼がひとつも積まれなくなっていました。

ほうれん草・レモン・味噌汁などが出ているのは、
この直しより前に登録されたものだからです。

ルール側の変更が要ることに気づいていませんでした。すみません。
