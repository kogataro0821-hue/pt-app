# 追加仕様の報告 — 導入の演出

アプリの入口に2つ、演出を入れました。

**Firestore Rules は変えていません。貼り直しは不要です。**

---

## 1. ログイン画面の前に1枚（濃紺の画面）

ログアウトしている状態でアプリを開くと、ログイン画面の**前に**1枚出ます。

```
        ┌────┐
        │ ◆ │        ← アプリの絵柄（最初から見えています）
        └────┘
         たろZAP

    速さより、続くかどうか        ← 1行目が にじみ出る
    小さく積んだものだけが        ← 1.4秒後に2行目
    あとから形になる              ← さらに1.4秒後に3行目

        ( 次へ進む )              ← 最初から見えています
```

**触るとログイン画面に進みます。** 「次へ進む」を押しても、画面のどこを触っても同じです。

### 動きについて

**上下に動かしていません。** その場でぼけた状態から焦点が合って濃くなる、にじみ出る形です。動かすと「出てきた」に見えますが、動かさないほうが「浮かび上がってきた」に見えます。

**1行1.5秒、1.4秒間隔。** 3行そろうまで約4.9秒です。速いと「表示された」だけで終わって、言葉として読まれません。

### ★ 待たせません

- **動いている途中でも、触ればすぐ進みます。** 「見終わるまで進めない」は、急いでログインしたい人の邪魔しかしません
- **「次へ進む」は最初から見えています。** 出そろうまで隠す形も作ってみましたが、急いでいる人には「まだ押せない」ように見えて不親切でした
- キーボードでも進めます。**約11秒放っておくと自動で進みます**（触り方が1つしかない全画面は、それが効かない人には行き止まりです）
- **ログインに失敗しても、もう一度見せません。** 一度進んだらログイン画面に留まります。パスワードを間違えるたびに名言を読まされるのは嫌がらせです

## 2. その日ぶんのかけらが入ったとき

ログインして最初に開いたとき、かけらが入った瞬間に全面で出ます。

```
    こんばんは、田中 花子さん
           ◆              ← 落ちてきて、着いたところで光の輪が広がる
     きょうのぶん +1 かけら
       ぜんぶで 12 かけら
      どこでも触ると閉じます
```

あいさつは時間帯で変わります（朝4時〜10時台／11時〜17時台／18時〜朝3時台）。**深夜2時は「こんばんは」**です。かけらの1日は朝4時区切りですが、あいさつは時計どおりにしました。午前2時に「おはよう」と言われると気味が悪いだけなので。

### ★ 1日1回になる仕組み

**回数を数える仕掛けは入れていません。** かけらは1日1つしかたまらないので、「受け取れた瞬間」に出すだけで自然に1日1回になります。

このアプリは1日に何度も開きます（朝昼晩の記録のため）。開くたびに演出が入ると、3日で「早く終われ」になります。記録アプリで入口が重いのは致命的です。

**どこを触ってもすぐ消えます。** 2.8秒で自動的にも消えます。Esc でも消えます。

**管理者が代理で契約者の画面を見ているときは出ません。** トレーナーが様子を見ただけでその人のかけらが増えては困るので。

## 3. 言葉について（10個・日替わり）

```
速さより、続くかどうか / 小さく積んだものだけが / あとから形になる
食べたものを知ることが / いちばん効く / 記録は、そのための道具
休んだ日も / やめた日ではない / 戻ってきた人が、いちばん伸びる
体重は毎日ぶれる / その日の数字ではなく / ひと月の流れを見る
完璧な一日より / ふつうの一週間 / それが積み上がっていく
減らすことより / 整えること / 続けられる形を探す
迷ったら、まず書く / 書けば見えて / 見えれば直せる
体は、あなたが選んだもので / できている / 今日の一食も、その一部
できなかった日を数えず / できた日を数える / それだけで前に進む
はじめる日は、いつも今日 / 昨日の自分と比べて / 少しだけでいい
```

### ★ 実在の人の名言は載せていません

筋トレ・ダイエットの世界に流れている「◯◯の言葉」は、**本人が言っていないものが本当に多い**です。出典不明のままアプリに刷ると、その責任はこちら側になります。このアプリのために書いた言葉だけを置き、誰の名前も付けていません。

### ★ 内容に枠を決めました

- **自分を責めさせない**（「甘え」「怠け」のような言い方はしない）
- **極端を勧めない**（絶食・限界まで・毎日必ず、などを煽らない）
- **休んだ日を否定しない**

記録アプリを開くたびに責められるのは、続ける妨げになります。**この枠はテストで固定してあります**（禁じた言い方が入ると失敗します）。あとで言葉を足すときにも効きます。

### 句点（。）は使いません

浮かび上がる文字の最後に丸が付くと、そこだけ重く見えます。1つだけ残っても浮くので、まるごと使っていません。区切りは「、」でつなぎます。**これもテストで固定してあります。**

### 3行の切れ目は、言葉の側で決めています

画面に折り返させると、端末の幅で切れ目が変わります。1行ずつ出る作りなので、切れ目が意味とずれると読んで引っかかります。

### 差し替えについて

**管理者が後から書き換える形にはできません。** ログイン前は Firestore から何も読めないためです（Rules でそう締めてあります）。差し替えたいときは言ってください。

もし「トレーナーが書いた言葉を出したい」なら、**②の毎日の演出側**のほうが向いています（そちらはログイン済みなので読めます）。

## 4. 直した不具合

**言葉が日替わりになっていませんでした。**

「文字コードを足して、言葉の数で割った余り」で選んでいたのですが、日付は1日で下1桁が1しか動きません。位の重みを掛けたぶんがちょうど言葉の数の倍数とぶつかり、**次の日も同じ言葉**が出る状態でした。言葉を14個から10個に減らしたときに、まさにそうなりました。

掛けて混ぜる形に直しました。いま1年ぶん試すと、**前日と同じになるのは335日中3回**、10個すべてが出ます。テストで固定してあります。

---

## 5. 動きを減らす設定の端末では

- ログイン前の1枚 … **最初から全部出ています**（1行ずつ現れるのは、人によっては読みづらさにもなります）
- その日ぶんの演出 … **そもそも出しません**（画面いっぱいに動くものは、人によって具合が悪くなります。受け取れた事実は札の数字に出ているので困りません）
