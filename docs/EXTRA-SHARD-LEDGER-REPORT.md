# 追加仕様の報告 — かけらの帳簿 と 交換QRの保存

かけらの出入りを1件ずつ残すようにしました。
あわせて、よく使う交換QRを保存できるようにしました。

> ## ⚠ Firestore Rules を貼り直してください
>
> **今回も Rules を変えています。** 貼り直さないと、帳簿が書けず交換も止まります。

---

## 1. 前はこうでした（正直なところ）

契約者1人につき、**いちばん最後の交換1件だけ**しか残っていませんでした。同じ人が2回目を交換すると、1回目は上書きされて消えていました。

1か月後に「先週プロテインと交換したはず」という話になっても、確かめる手立てがありませんでした。**実物と交換する数字としては、足りていませんでした。**

---

## 2. 帳簿ができました

契約者の設定画面（歯車）の「タンパク質のかけら」の下に、**出入りの記録**が出ます。

```
出入りの記録
渡した 12 ◆ ／ 使った 8 ◆
毎日たまるぶんは入っていないので、この合計は残高と一致しません。

┃ 9月6日 15:04  プロテイン1杯   −3 ◆   残り 2 ◆
┃ 本人が交換
  9月5日 10:22  今月おつかれさま +5 ◆   残り 5 ◆
  トレーナー
```

- **管理者が付けた・引いたぶん**も入ります
- **本人がQRで交換したぶん**も入ります
- 左に線が入っているのが「本人が交換した」行です。トレーナーが動かした行と混ざると、後から誰がやったのか分からなくなるので分けました

### ★ 毎日の +1 は、わざと入れていません

10人 × 365日で年に数千件になります。開くたびに重くなるわりに、「これまで◯日」で分かる話です。**帳簿に残すのは、人が動かしたぶんだけ**にしました。もめるのは、いつもそちらです。

そのため、**帳簿の合計は残高と一致しません。** 不具合ではありません。画面にもその一行を出しています（書かないと「計算が合っていない」と見えるので）。

---

## 3. ★ 帳簿の値打ちは「消せないこと」です

契約者は**書き足せますが、消せません。**

自分の交換は自分で書きます（そうしないと交換できません）。ただし Rules で書き換えと削除を管理者だけにしてあるので、**後から都合の悪い行を消すことはできません。**

あわせて、次も止めています。

| やろうとすること | 結果 |
|---|---|
| 書いた行を、あとから消す | **通りません** |
| 書いた行を、あとから書き換える | **通りません** |
| 「トレーナーから3もらった」を自分で書く | **通りません** |
| 「トレーナーがやった」体の行を書く | **通りません** |
| 端末の時計で時刻を書く | **通りません**（サーバー時刻のみ） |
| 他人の帳簿を読む・書く | **通りません** |

---

## 4. 交換QRを保存できます

「交換QR」の画面に、**保存した交換**の一覧が出ます。

```
保存した交換
┌──────────────────────┐
│ ドリンク1本        1 ◆  │ [消す]
│ プロテイン1杯      3 ◆  │ [消す]
│ タオル            10 ◆  │ [消す]
└──────────────────────┘
```

押すと、その内容でQRが出ます。**毎回同じ内容を打ち直す必要がありません。** 打ち直すたびに数を間違える余地も消えます。

内容を入れて「この内容を保存する」で増えます。同じ内容がすでにあれば「保存ずみ」になり、二重に増えません。50件まで。

**並びは安い順**にしました。交換の場でいちばん多いのは「いま持っているぶんで何ができるか」だからです。新しい順だと毎回いちばん上が入れ替わって探しにくくなります。

### QRの絵そのものは保存していません

保存しているのは**内容と数だけ**で、QRは毎回その場で描いています。絵を保存すると、置き場所（URL）が変わったときに、古いQRが黙って使えなくなるためです。

---

## 5. 直したこと

**契約者を完全に削除したときに、帳簿が消し残っていました。**

Firestore は親を消しても下位のコレクションが残ります。帳簿を足したときに削除処理へ入れ忘れていて、**消したはずの契約者の記録が、画面から見えないまま残る**状態でした。

これは自分で気づいたのではなく、**前に作っておいた見張りのテストが止めてくれました**（新しいコレクションを足したのに削除処理に入れていないと失敗するテストです）。入れ忘れは直してあります。

---

## 6. Rules の貼り直し

1. Firebase コンソール → Firestore Database → **ルール** タブ
2. `firebase/firestore.rules` の中身を**すべて**貼り付け
3. **公開** を押す

---
