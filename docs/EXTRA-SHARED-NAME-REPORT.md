# 追加仕様の報告 — まとめ呼び（「とうふ」で両方出す）

**Firestore Rules は変えていません。貼り直しは不要です。**

---

## 1. まず、調べて分かったこと

動かして確かめました。**話が2段ありました。**

### 「とうふ」と打つと、そもそも0件でした

```
「豆腐」と打つ  → 豆腐（木綿） 木綿豆腐 絹ごし豆腐 絹豆腐   4件出る
「とうふ」と打つ → （何も出ない）                          0件
```

**漢字を読みに直す処理を持っていません。** カタカナ→ひらがなは直しています（ﾄｳﾌ → とうふ）が、漢字→読みは辞書が必要で、アプリに同梱できる大きさではありません。

だから、ひらがなで当てたいなら**読みを別名として登録するしかありません**。やろうとしていたことは正しいです。

### その別名を2件に付けると、黙って片方が選ばれていました

木綿豆腐と絹豆腐の両方に別名「とうふ」を付けて「とうふ」と打つと、**木綿豆腐だけが確定して、絹豆腐は出てきませんでした。** 画面には何も出ません。

「名前がぶつかっています」の警告は、まさにこれを警告していたものです。**警告は正しかった**のですが、その結果「別名を付けてはいけない」と読まれて、機能が封じられていました。

---

## 2. 何を直したか

**危なかったのは「同じ名前が2つあること」ではなく、「黙って1つに決めていたこと」でした。** そこを直しました。

### ★ 2件以上当たったら、確定させません

```
食材の名前  [ とうふ            ]

「とうふ」で2件あります。どれか選んでください
┌────────────────────────────┐
│ 木綿豆腐   「とうふ」· 73kcal · P7 F4.2 C1.5 │
│ 絹豆腐     「とうふ」· 56kcal · P5.3 F3.2 C2 │
└────────────────────────────┘
```

- **選ぶまで保存できません。** ここを開けておくと「マスタに無い」扱いで保存され、**登録依頼まで飛びます**。マスタにはちゃんとあるのに、です。管理者に「とうふを登録してください」と届いても、何を登録すればいいのか分かりません
- **選ぶまで、栄養値の入力欄を出しません。** マスタにあるのに手入力させることになるので
- 本名（木綿豆腐）をそのまま打てば1件なので、今までどおり即確定します

### ★ 管理画面の表示を2種類に分けました

分かれ目は **その呼び名を本名にしている食材がいるかどうか** です。

| | 判定 | 画面 |
|---|---|---|
| とうふ（どちらの本名でもない） | **まとめ呼び** | 一覧で表示するだけ |
| たまご（eggOld の本名） | **ぶつかり** | 今までどおり警告 |

```
まとめ呼び（1件）
この呼び名で打つと、下の食材がぜんぶ候補に出ます
契約者はその中から選びます。勝手に決まることはありません

  とうふ → 木綿豆腐・絹豆腐
```

本名が取られている場合は、片方が相手の名前を名乗っている状態です。**選ばせる画面に出しても「卵／たまご」と並ぶだけで見分けられません。** だからこれは今までどおり直してもらいます。実際に起きた「卵が2件」は、こちらに残ります。

警告の文も直しました。以前は「どちらの栄養値が使われるか決まりません」と書いていましたが、**いまは決まらないときは選ばせるので、その文は嘘になりました。**

### ★ 別名の欄に説明を足しました

```
別名（読み方や書き方のゆれ）
[ 鶏胸肉、とりむね、ムネ肉        ]
「、」で区切って入れてください
ひらがなで打って当てたいときは、読みを入れてください（豆腐 →「とうふ」）
同じ別名を複数の食材に付けられます
木綿豆腐と絹豆腐の両方に「とうふ」を入れておけば、
「とうふ」と打ったときに両方が候補に出ます
```

書いていなかったせいで封じられていた機能なので、欄のところに書きました。

## 3. やってもらうこと

**木綿豆腐と絹豆腐の別名に、それぞれ「とうふ」を入れてください。** 食品マスタ → その食材 → 別名の欄です。

警告は出ません。代わりに一覧の上に「まとめ呼び（1件） とうふ → 木綿豆腐・絹豆腐」と出ます。

ほかの食材も、**打つ回数が多いものだけ**読みを足していくのがいいと思います。全部に入れると、新しい食材を登録するたびに読みを入れる手間が増えます。

## 4. 気をつけてほしい副作用

**AIに食事の文章を読ませる画面では、まとめ呼びは自動で当たりません。**

「とうふ 150g」と書かれても、2件あって決められないので「マスタに無い」扱いになります。そこは人が選ぶ画面ではないので、**勝手に片方の数字を入れるより、当てないほうがましだ**と判断しました。名前を「木綿豆腐」に直せば当たります。

気になるようなら、あちらにも選ばせる形を入れられます。言ってください。
