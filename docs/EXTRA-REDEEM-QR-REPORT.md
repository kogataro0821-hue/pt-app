# 追加仕様の報告 — かけらの交換QR

管理者がQRを作り、契約者が読んでその場でかけらを使えるようにしました。
あわせて、画面の「かけら」の文字を**金色の石の絵**に変えました。

> ## ⚠ Firestore Rules を貼り直してください
>
> **今回も Rules を変えています。** 貼り直さないと交換できません。

---

## 1. 使い方

**管理者** … メニューの **「交換QR」** を開く

```
交換するもの   [ プロテイン1杯        ]
かけらの数     [ 3 ]   [1][3][5][10][30]

        ┌──────────┐
        │  QR       │   ← これを見せる、または印刷して貼る
        └──────────┘
```

**契約者** … スマホの**普通のカメラ**をQRに向ける → 出てきたリンクを開く → 内容と数を確認して「3つ払って交換する」

アプリを開く必要も、カメラの許可も要りません。**QRの中身がアプリのURLなので、標準のカメラがそのまま読みます。**

---

## 2. ★ ここがいちばん大事です

**契約者のスマホに出る「交換しました」の画面は、証拠になりません。**

契約者の端末が出す画面なので、作ろうと思えば作れます。PayPay はサーバーが確かめるので成立しますが、このアプリにサーバーはありません。

そこで、**交換QRの画面に「受け取り」欄**を付けました。

```
受け取り
┌─────────────────────────────┐
│ ◆ 田中 花子  プロテイン1杯  3   残り 9  │
└─────────────────────────────┘
```

**ここに出たら、かけらが確かに引かれています。** Firestore を直接見て出しているので、相手の画面の見た目とは関係ありません。

**交換の場では、相手のスマホではなく、こちらの画面をご覧ください。** 画面にもその一文を出しています。

---

## 3. QRは「値札」です

QRの中身は「いくつ」と「なんの交換か」だけで、**誰あてかは入っていません。** 読んだ人が自分のぶんを払います。

つまり **何度でも使えます。** 印刷してプロテインの棚に貼っておけば、毎回作り直す必要はありません。

---

## 4. ごまかせないようにした点

Rules で、次のことを全部確かめています。

| やろうとすること | 結果 |
|---|---|
| 3引いたことにして、1しか引かない | **通りません** |
| 何も引かずに控えだけ書く | **通りません** |
| 残高より多く引く（マイナスにする） | **通りません** |
| マイナスの数で、逆に増やす | **通りません** |
| 端末の時計で「さっき払った」と書く | **通りません**（サーバー時刻のみ） |
| 交換にまぎれて他の項目を書き換える | **通りません** |
| 他人のかけらを交換する | **通りません** |

とくに1行目が要です。**減った数と、控えに書いた数が一致していないと通しません。** これがないと「払いました」の画面だけ本物になります。

Rules テストを17件足しました（push すれば GitHub が流します）。

---

## 5. 決めたこと

**取り消しは付けていません。** 付けると、交換したあとに押し戻せてしまいます。間違えたときは**トレーナーが増やして戻す**運用にしました（設定画面から1タップです）。押す前に「あとから取り消せません」と出しています。

**管理者が代理で開いても交換できません。** トレーナーが確認のつもりで開いて、その人のかけらが減っては困るので。

**おかしいQRでは交換画面を出しません。** 数が0・マイナス・文字・桁が大きすぎる・内容が空、はすべて「交換できません」で止めます。とくにマイナスは、通すとQRを読むだけでかけらが増えてしまいます。

---

## 6. ★ 実機で確かめていただきたいこと

1つ、こちらでは確かめられない懸念があります。

**QRから開いたときに、ログインし直しになるかもしれません。**

iPhone は「ホーム画面に追加したアプリ」と「Safari」で保存領域が別になることがあります。カメラから開くと Safari 側で開くので、そちらでログインしていないと入力を求められる可能性があります。

**まずご自身の端末で一度お試しください。** もしログインを求められるようなら、別のやり方（アプリ内にQRの読み取りを作る、コード番号を打ってもらう）に切り替えられます。

---

## 7. かけらの絵

「1 かけら」という文字を、**金色の石の絵**に変えました。

- 画像ファイルではなく、その場で描いています（拡大しても粗くならず、読み込みも増えません）
- 面ごとに濃さを変え、上に光の点を3つ乗せて、ゆっくり瞬かせています
- **動きを減らす設定の端末では光りません**（一覧に何個も並ぶ絵が動き続けると、酔うような不快感が出るため）
- 目が見えない方には「12 かけら」と読み上げられます

---

2. `firebase/firestore.rules` の中身を**すべて**貼り付け
3. **公開** を押す
