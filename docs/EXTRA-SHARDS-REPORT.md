# 追加仕様の報告 — タンパク質のかけら（旧: ログインポイント）

単位を「ポイント」から **タンパク質のかけら** に変えました。
あわせて、その場で増減できる欄を契約者ごとの画面に足しました。

> ## ⚠ この2つを、順番どおりにお願いします
>
> 1. **Firestore Rules を貼り直す**（1日にたまる数の既定値が変わっています）
> 2. **いま 100pt 貯まっている方を 1 かけらに直す**（手順は「4. 換算」）
>
> 1 をやらずに配ると、契約者の画面でかけらがたまりません。

---

## 1. 単位が変わりました

**100pt = 1 タンパク質のかけら。** 画面から「pt」という言葉は消えます。

| | 前 | いま |
|---|---|---|
| 呼び名 | ポイント / pt | **タンパク質のかけら**（短く「かけら」） |
| 1日にたまる | 100 | **1** |
| 1日の設定の範囲 | 0〜10000 | **0〜100** |
| 一度に動かせる上限 | 100000 | **1000** |

朝4時の区切りと、休んでも減らないところは、そのままです。

---

## 2. その場で増やす・減らす（新しく足しました）

契約者ごとの設定画面（歯車）に、こういう欄を置きました。

```
タンパク質のかけら
いまの残高  12 かけら

[  3  ] [ 減らす ] [ 増やす ]
[1][3][5][10]

ひとこと  [ プロテインと交換しました        ]

押した瞬間に反映されます（「保存する」は不要です）。
```

**目の前に本人がいるとき用**です。交換したその場で1回押して終わります。

- **押した瞬間に反映されます。** 保存ボタンは押さなくて結構です
- 本人にもお知らせが届きます。数字だけ黙って減っているのが、いちばん不安にさせるためです
- 残高より多く引いても、マイナスにはなりません。引ききれなかったら、その場でそう出ます

「かけら」タブ（一斉送信の画面）は残してあります。**複数人にまとめて配るときと、長い文章を添えたいとき**はそちらが向いています。1人だけならこの新しい欄のほうが速いです。

---

## 3. 減らすのに、時間の制限はありません

念のため、確かめて明記しておきます。

**朝4時の区切りは「契約者が自分でその日ぶんを受け取る」ときだけの条件です。**
管理者の増減には、日付も時刻も一切かかっていません。いつでも、何度でも減らせます。
Rules のテストにも、そのままの文で2件足しました。

- その日ぶんを受け取ったあとでも、いつでも減らせる
- その日ぶんをまだ受け取っていなくても、減らせる

ただし1つだけ、見え方の注意があります。**その日まだアプリを開いていない方から引くと、あとで本人が開いたときに今日ぶんの1かけらが入ります。** 引き算は効いていますが、別口で足されるので「戻った」ように見えます。気になるときは、ひとこと欄に理由を書いておくと、お知らせに残るので後から追えます。

---

## 4. 換算 — いま 100pt 貯まっている方

**100pt = 1かけら** なので、その方は **1かけら** になります。
自動では変換しません。画面から2手でお願いします。

**手順**

1. Rules を貼り直す（下の「5.」）
2. 契約者の設定画面（歯車）を開く
3. 「タンパク質のかけら」の欄で **99** と入れて **「減らす」** を押す
   → 残高が 100 → **1** になります
4. 同じ画面の下、**「1日にたまるかけらの数」** を確認する
   - **100 になっていたら 1 に直して、「保存する」を押してください**
   - 空欄・未設定なら、そのままで大丈夫です（既定の1が使われます）

**4 は全員ぶん確認してください。** ここが 100 のまま残っていると、その方だけ1日100かけら入り続けます。

自動変換にしなかったのは、一度きりの処理のために変換コードを本体に残すと、あとで二重に走る事故が起きるからです。人数が少ないうちは、手で確実にやるほうが安全だと判断しました。

---

## 5. Rules の貼り直し

1. Firebase コンソール → Firestore Database → **ルール** タブ
2. `firebase/firestore.rules` の中身を**すべて**貼り付け
3. **公開** を押す

変えたのは1か所です。1日にたまる数の既定値を **100 → 1** にしました。
ここがコード側とずれると、受け取りが静かに弾かれ続けます。
