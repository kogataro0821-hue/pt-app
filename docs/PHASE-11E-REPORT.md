## 2. 何を作ったか

### 数え方

```
ログイン証明の確認  →  今日すでに何回使ったかを見る  →  上限内なら1つ増やして通す
                                                   →  上限に達していたら 429 で断る
```

数え札は Cloudflare KV に置きます。**1人ごと・1日ごとに別の札**です。

| 決めたこと | 値 | 変え方 |
|---|---|---|
| 1人が1日に使える回数 | **50回** | Cloudflare の設定に `DAILY_LIMIT` を足すだけ（貼り直し不要） |
| 日付の変わり目 | **日本時間の午前0時** | — |
| 札の保存期間 | 48時間で自動的に消える | — |

### 日付の変わり目を日本時間にした理由

世界標準時のままだと、回数が戻るのは**日本の朝9時**です。
利用者から見れば「昼前になったら急に使えるようになった」で、説明のしようがありません。

### 上限に達したときの画面

これまで 429 は、すべて「AIの利用が混み合っています。**しばらく待ってから**お試しください」でした。

**1日の上限にこの言い方をすると、戻らないものを一日じゅう待つことになります。**
そこで、中継役が「混み合い」と「1日の上限」を別の名前で返し、画面も言い分けるようにしました。

| 何が起きたか | 画面に出る文 |
|---|---|
| Gemini が混雑 | AIの利用が混み合っています。**しばらく待ってから**お試しください。手で入力することもできます。 |
| 1日の上限に達した | 今日のAIの利用回数が上限に達しました。**日付が変わると、また使えます。**手で入力することもできます。（1日50回まで） |

どちらも「手で入力できる」ことは必ず伝えます。**AIが止まる＝その日の記録が止まる、にはしません。**

## 3. ★ 数えられないときは、止めません

これは意図した判断なので、はっきり書いておきます。

**KV を結び付け忘れていても、KV が一時的に応答しなくても、AIは今までどおり使えます。**

理由は、ここで守っているものが**無料枠であって、利用者のデータではない**からです。
契約者どうしの分離のような「絶対に通してはいけないもの」なら、迷わず止めるべきです。
しかし回数の数え札が置けないことで、契約者全員がAIを使えなくなるのは行き過ぎです。

そのかわり、**結び付け忘れに気づける場所**を作りました。

WorkerのURLをブラウザで開くと、こう出ます。

```
"dailyLimit": "有効（1人あたり1日 50 回まで）"        ← 数えています
"dailyLimit": "⚠ 数えていません（KV名前空間 RATE_LIMIT が結び付けられていません）"
```

**この画面にAPIキーは一切出ません。** 撮って送っていただいて大丈夫です。

---

## 4. 正直に — この数え方は厳密ではありません

Cloudflare KV は「少し前の値が返ることがある」作りです。
**同時にたくさん飛んでくると、数え落として上限を数回超えることがあります。**

それでいいと判断しました。ここで受け止めたいのは次の3つで、どれも
「1回たりとも超えさせない」必要がないためです。

| 起きること | 数え方で足りるか |
|---|---|
| アプリの不具合でAIを呼ぶ処理が繰り返される | ○ 繰り返しは順番に飛ぶので、確実に止まります |
| 契約者が面白がって連打する | ○ 同上 |
| 端末を盗られてトークンが漏れる（1時間以内） | △ 数十回は余分に通るかもしれませんが、桁は変わりません |

1回も超えさせない仕組みが要るなら KV では足りず、Durable Objects（有料）が必要です。
**そこまでの必要はありません。**

---

## 5. あわせて直したこと — 本文の大きさの数え方

上限の判定が `body.length` になっていました。これは**文字の数**で、バイト数ではありません。

日本語は1文字3バイトなので、上限2,000,000は**実際には約6MBまで通っていました。**
`new TextEncoder().encode(body).length` に直しました。

写真は base64（半角）なので、写真の経路では元から意図どおりに効いていました。
**実害はありませんでしたが、書いてあることと違うので直しました。**

先にコードを貼ると、KVができるまでの間は数えない状態になります。
（壊れはしませんが、確認のとき「⚠ 数えていません」と出て、迷うことになります）

**「worker.js を新しくするとき」** に書きました。

**カード登録は不要です。** KV の無料枠は 書き込み1,000回/日 で、
このアプリの想定は約50回/日です。桁が2つ違います。

### 固定した約束

| 確かめたこと |
|---|
| 上限に達したら **Gemini まで1回も届かない**（届いていたら無料枠は減り続けます） |
| **門で止められた人は、回数を消費しない**（外から叩かれるだけで契約者が使えなくなるのを防ぐ） |
| 鍵が未設定のときは、回数を消費しない（設定ミスのせいで枠を減らさない） |
| 人ごと・日付ごとに別々に数える |
| **KV が無くても、壊れていても、アプリは止まらない** |
| 日本時間の午前0時で戻る（世界標準時ではない） |
| 上限の設定がおかしい値（`0`・空・文字）のときは既定に戻す ← ここで全員止まると最悪です |
| 上限で断ったことがログに残る（「壊れた」のか「使い切った」のかが分かる） |
| 日本語の本文が、バイト数で 413 になる |
