# 追加仕様の報告 — グラム数が書いていない商品

成分表示から読み取ったとき、グラム数が無くても先に進めるようにしました。

**Firestore Rules は変えていません。貼り直しは不要です。**
（食品マスタは元から管理者だけが書ける場所なので、項目を足すだけで済みます）

---

## 1. 何が変わったか

「1食当たり」とだけ書かれていてグラム数が無い商品で、**赤い文字が出て止まっていた**ところに、選択肢を出すようにしました。

```
1回分は？

 [ グラム数を入れる ]  [ 「1袋ぶん」で登録 ]
```

**左（既定）** … これまでどおりです。分かるならこちらが正解です。

**右** … 表示の数字を「1袋ぶん」として登録します。グラム数を一度も知らずに済みます。

単位は **個・枚・本・袋・パック** から選べます（`袋` を新しく足しました）。

---

## 2. 先にお伝えしたいこと（右を選ぶと失うもの）

**「1袋ぶん」で登録した食材は、グラムで量れなくなります。**

内部では「1袋 = 100g」という**嘘の重さ**を置いています。1袋・0.5袋と入れるぶんには計算はぴったり合いますが、その食材の「100gあたり」には意味がなくなります。

袋ごと食べる商品（インスタント麺、プロテインバー、個包装のお菓子）なら困りません。**大袋から少しずつ取る商品には向きません。**

選ぶ画面にも、この一文を出してあります。

---

## 3. 取り違えないための印

数字だけ入れて済ませると、半年後に見た人が「100gでこのカロリー？」と誤解します。なので食品マスタに**印**を持たせました。

- 食材の編集画面で、見出しが `100gあたり` ではなく **`1袋あたり`** になります
- その下に「グラムでは量れません」と出ます
- 食事に追加するとき、量の欄に **100（＝1袋）が最初から入ります**
  「1袋なら 100、半分なら 50」と案内が出ます

---

## 4. グラム数が分かるときは、そちらが優先されます

念のため、テストで固定してあります。

**グラム数が読み取れているときは、単位を選んでいてもグラム数のほうを使います。** 分かっているなら、本当の100gあたりのほうが価値があるからです。

また、**「1袋ぶん」を選んでも、炭水化物が読めていなければ止まります。** グラム数の話と、数字が足りない話は別だからです。

---

## 5. パッケージの「内容量」を先に探してみてください

グラム数は、成分表示の**表の中**に無くても、**パッケージのどこかに「内容量 ○g」として書いてあることがほとんどです**（表示が義務づけられているため）。裏面の下のほうや、商品名の近くです。

AIが読んでいるのは成分表示の表だけなので、そこに無ければ「読み取れなかった」になります。**表に無いだけで、パッケージには書いてあることが多い**ので、一度ご確認いただくと、本当の100gあたりが手に入ります。

その手間が惜しいときのために、右の道を用意した、という位置づけです。

---

## 6. やらなかったこと

**基準を「100g当たり」に変えて通す**、という抜け道は塞いでいません（表示の基準は今も選び直せます）。ただし**これをやると、1袋ぶんの数字が「100gぶん」として保存され、しかも間違いに気づけません。** 使わないでください。

「1袋ぶん」を選ぶほうは印が残るので、あとから見分けられます。
