# 追加仕様の報告 — 会員ランク

カレンダーの下に会員証を置きました。**Firestore Rules は変えていません。貼り直しは不要です。**

---

## 1. ランクと条件

| ランク | 上がる条件 |
|---|---|
| **PLATINUM** | 登録時の初期ランク |
| **RUBY** | 食事を**連続21日**記録（1日1件でも可） |
| **SAPPHIRE** | 運動を記録した日が**累計16日** |
| **EMERALD** | 食事**累計90日** かつ 運動**累計24日**（両方必須） |
| **DIAMOND / CROWN / CROWN AMBASSADOR** | **あなたが契約者ごとに条件を決めます**（第2章） |

- **順番を飛ばしません。** 運動だけ達成しても、RUBY より先へは行きません
- ただし条件が同時にそろえば、**一度に何段でも上がります**（PLATINUM →（1回で）EMERALD もありえます）
- **自動での降格はありません。** 記録が減ってもランクは下がりません
- あなたは **「下げる」ことだけ**できます。上げるのは条件を満たしたときだけです

### 「最初の21日間」を「連続21日」に変えました

ご指定は「最初の21日間100%」でしたが、**連続21日**にしています。

最初の21日に限ると、**入会2日目に寝落ちした人が、以後ずっと PLATINUM のまま**になります。
RUBY になれないので SAPPHIRE にも EMERALD にも進めません（RUBY 優先のため）。

やり直せる形のほうが、続ける仕掛けとして機能すると判断しました。
「最初の21日限定」に戻したい場合は、条件を1行変えるだけです。

### 見た目について（ご要望の反映）

- 会員証を**カレンダーの上**に移しました。カレンダー上部にあった名前は消しました（会員証に入っているため）
- カードに出す名前を、会員IDから**表示名**に変えました
- ランク名を筆記体から**ゴシック体（太字）**に変えました
- **金の箔押しの装飾**（内側の二重線＋四隅の飾り）と、紙の質感を足しました
- **DIAMOND を作り直しました。**PLATINUM との差が出なかったためです（第3章）

### 「16回」は「16日」で数えています

1日に運動を3件入れても1日です。EMERALD の「24日間の運動報告」と数え方をそろえました。
件数で数えると、細かく分けて入れる人ほど早く上がってしまいます。

## 2. DIAMOND から先の条件

契約者ごと・ランクごとに、**3つ選んで決めます。**

| 選ぶもの | 選択肢 |
|---|---|
| 何を | 食事記録 ／ 運動記録 |
| どう | 累計 ／ 連続 |
| 何日 | 1〜3650 |

例）「運動記録・連続・30日」。

**決めていないランクへは、記録がいくらあっても上がりません。**
目標を渡していないのに上がるのは、おかしいためです。画面には「未設定」と出ます。

> ★ 欄をもっと増やせば細かく決められますが、**決めるのが面倒になれば結局決めないまま**になります。
> 決めやすさを優先して3つにしました。足りなければ言ってください。

### ★ 設定画面からは、ランクを上げられません

上げるのは「条件を満たしたとき」だけです。設定画面から好きなランクにできてしまうと、
**条件を決めた意味がなくなります。**

下げるほうは、いつでもできます。**いまより下なら、どこへでも**下げられます
（SAPPHIRE の人を一気に PLATINUM まで下げられます）。下げるときは確認が出ます。

## 2.5 ★ 昇格を確定するのは、あなたです

契約者が自分でランクを書けるようにはしていません。**書けるようにすると、アプリを迂回して直接 CROWN AMBASSADOR にできます。**
「契約者は自分の権限を上げられない」という、このアプリで一番重い約束と同じ性質の話です。

| | 見えるもの |
|---|---|
| **契約者の画面** | 「RUBY の条件を満たしました。**トレーナーの確認をお待ちください**」（押せるボタンは1つも出ません） |
| **あなたの画面** | 「**RUBY に昇格させる**」ボタン。押すとその場で切り替わります |

Security Rules 側でも塞がっています（`clients` の更新で契約者に許した項目に `rank` は入っていません）。
テストで10件固定しました。

### 気づける仕組みも入れました

条件を満たしたことを、あなたが知る手段がないと意味がありません。
そこで、**契約者一覧に「RUBYに昇格できます」のバッジ**が出るようにしました。

仕組みはこうです。契約者の画面で数えた結果を、契約者が書ける唯一の欄（`extra`）に1語だけ書き残します。
一覧はもともと契約者の情報を読んでいるので、**追加の読み取りは0回**です。

> ★ この目印は契約者が書けますが、危なくありません。
> **印が出るだけで、ランクは上がりません。** 上げるのはあなたで、そのとき本物の数字が画面に出ています。

## 3. 会員証に出しているもの

**カードはクレジットカードと同じ比率です（85.60 × 53.98mm ＝ 1.586 : 1）。**
実物のカードと同じ形にすると、「持っているもの」として認識されます。

```
┌──────────────────────────────────────┐
│ [たろZAPロゴ]               No. 0003 │
│                                      │
│   RANK  𝑅𝓊𝒷𝓎              ← 筆記体   │
│                                      │
│ taro              MEMBER SINCE 2026.04│
└──────────────────────────────────────┘
   ┌────────────────────────────┐
   │ 次は SAPPHIRE              │   ← カードの外
   │ 運動を記録した日数   12/16 │
   │ ████████░░░░               │
   └────────────────────────────┘
                  食事 87日／運動 22日
```

**カードの中に入れるのは5つだけ**にしました。ロゴ・整理番号・ランク・会員ID・入会年月。
進み具合や累計を中に詰め込むと、比率が崩れるか、字が読めない大きさになります。

**進み具合は、カードのすぐ下にいちばん大きく出しています。**
いまのランクは「済んだこと」で、明日の行動を変えるのは「あと何日か」のほうだからです。

EMERALD より上では進み具合を出しません。記録の量で決まらないので、
「あと何日で上がる」と誤解させないためです。代わりに
「ここから先のランクは、トレーナーが決めます」と出します。

### ロゴ

たろZAP のマークを、背景の黒を抜いて（透過して）入れています。
**どのランクでも同じマークです。** ただし明るい地のランク（PLATINUM / DIAMOND / CROWN）では
金が背景に溶けるので、**細い暗い縁だけを足して浮かせています**（色は変えていません）。

### 会員整理番号

**既にいる契約者には、自動では振りません。**

契約者編集画面に「会員整理番号」の欄があります。手で入れて「整理番号を保存する」を押したときだけ付きます。
「次の番号を入れる」を押すと、いまの最大+1 が欄に入ります（**入るだけで、保存はまだされません**）。

| | |
|---|---|
| 空欄 | 未採番。会員証には `No. ----` と出ます |
| **`0`** | **使えます。**トレーナー自身のアカウントを `0000` にする、など |
| 新しく作った契約者 | 作成時に「いまある番号の最大+1」が自動で入ります |

一度決めた番号は、なるべく変えないでください。会員証の番号が変わると、別人の証になります。

> ★ `0` を使っても、その後の採番には影響しません。
> トレーナーのアカウントが `0000` なら、次に作る契約者は `0001` になります。

### 筆記体

Google Fonts の `Great Vibes` を1書体だけ読み込みます。
**読み込めなくても壊れません。** iPhone なら `Snell Roundhand`、それ以外でも端末の筆記体に落ちます。
ランク名は英字7語だけなので、日本語の表示には一切影響しません。

### 色と装飾

ランクが上がるほど「豪華に」しています。やっているのは4つだけです。

1. 背景を、その宝石の色にする
2. 光沢（斜めの明るい帯）を強くする
3. **金の装飾（内側の二重線＋四隅の飾り）を濃くする**
4. 紙の質感を強くする

**装飾の絵柄はどのランクも同じで、濃さだけが変わります。**
ばらばらの飾りにすると、並べたときに順位が読めなくなります。

| ランク | 見た目 |
|---|---|
| PLATINUM | 銀（明るい地に濃い文字） |
| RUBY | 深紅 |
| SAPPHIRE | 濃い青 |
| EMERALD | 深緑 |
| DIAMOND | **虹の反射＋四方にとがった輝き。**銀の板とは作りそのものを変えています |
| CROWN | 金 |
| CROWN AMBASSADOR | 黒地に**金の文字**（文字そのものを金のグラデーションに） |

派手さを足すのではなく、**同じ作りの中で段階を上げています。**
ばらばらの装飾にすると、並べたときに順位が読めなくなります。

## 4. 無料枠への配慮

ランクの判定には「食事を記録した日」「運動を記録した日」が要ります。

**下位コレクション（meals / exercises）は開いていません。** 日ドキュメントの
`hasMeals` / `hasExercise` を使っています。カレンダーの印のために元からある項目で、
ランクのために増やしたものではありません。

日ドキュメントを1回読むだけです（1年ぶんで365件）。しかも一度読んだら覚えておき、
**記録を足したときだけ数え直します。** 画面を移るだけでは読み直しません。

### DIAMOND を作り直した話

最初の DIAMOND は「白くて光沢の強い板」で、**PLATINUM（銀の板）との差が出ませんでした。**
同じ作りのまま明るさだけ変えても、別格には見えません。

そこで、作りそのものを変えました。

| | PLATINUM | DIAMOND |
|---|---|---|
| 見立て | 磨いた金属 | **光を割る石** |
| 面 | なめらかな一枚 | **境目のはっきりした面（カット）** |
| 色 | 銀一色 | **虹の反射（プリズム）** |
| 光 | 斜めの帯 | **四方にとがった輝き** |

きらめきは、丸いぼかしではなく**四方にとがった形**にしました。
丸だと「ぼんやり明るい」で終わり、宝石には見えません。

背景が忙しくなったぶん、文字はグラデーションをやめて濃い一色にし、
白い光を回りに置いています。**文字までキラキラさせると、どこも読めなくなります。**
