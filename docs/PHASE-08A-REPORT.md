# Phase 8A 報告 — AIによる入力の補助（文章から）

## 1. できたこと

### 契約者ごとの同意

契約者の「設定」画面に、AI利用の同意を置きました。

**同意していない人には、AIのボタンが一切表示されません。**
同意は本人だけが与えられ、本人だけが取り消せます。管理者が代わりに同意することはできません。

同意画面では、次のことを**隠さずに**書いています。

- 書いた文章がGoogleのAIサービスへ送られること
- **無料枠のため、送った内容がGoogleのAIの改善に使われる可能性があること**
- 名前・契約者ID・体重・目標値・他の日の記録は送らないこと
- いつでも取り消せること
- 同意しなくても、手入力ですべての機能が使えること

小さな字にも、専門用語にもしていません。読んだうえで断れることが、同意が同意であるための条件だからです。

同意文の版（`AI_CONSENT_VERSION`）を持たせてあります。文面を実質的に変えたら版を上げると、同意の取り直しになります。

### 中継役（Cloudflare Worker）

```
アプリ ──(ログイン証明)──▶ Worker ──(APIキー)──▶ Gemini
                             ▲
                        キーはここだけ
```

APIキーをアプリに入れると、公開リポジトリなので誰でも読めます。
そこでキーはWorkerの中だけに置きました。

**Workerがすること**

1. Firebaseが発行したログイン証明を検証する
2. APIキーを付ける
3. Geminiへ転送して、返事をそのまま返す

1が要です。これが無いと、URLを知った人は誰でもあなたのAI枠を使えます。

**外部の部品を一切読み込まない単一ファイル**にしてあります。
Cloudflareの管理画面に貼り付けるだけで動くので、パソコンに何かを入れる作業は発生しません。

### ★ 自前の署名検証を、CIで毎回検証しています

外部の部品を使わない方針にしたぶん、証明書から公開鍵を取り出す処理も、
トークンの検証も自前です。ここが甘いと、誰でもAI枠を使えてしまいます。

そこで **15件のテスト**を書き、CIで毎回実行しています。
その場で使い捨ての証明書を作り、本物と同じ手順で検証します。

- 取り出した公開鍵が、opensslの出力と**1バイト単位で一致する**こと
- 正しいトークンが通り、利用者IDが取れること
- **中身を書き換えたトークンが拒否されること**
- 署名が壊れたトークンが拒否されること
- **署名方式を `none` に変えたトークンが拒否されること**（古典的な攻撃）
- 別プロジェクト宛・発行元違い・期限切れ・未来発行が拒否されること
- 知らない鍵IDが拒否されること

### 文章からの入力

```
入力: 「白米180gと鶏むね肉、サラダ」
   ↓ AI
白米 180g       根拠「白米180g」    → マスタから栄養値が入る → そのまま追加できる
鶏むね肉 ?g     根拠「鶏むね肉」    → 「何グラムでしたか？」と質問
レタス 30g      根拠「サラダのレタス」→ ★ 原文に無いので破棄
```

## 2. ★ 設計書 §12「勝手な補完の禁止」を3層で受け止める

AIは、放っておくと書かれていないことを足します。
「サラダ」としか書いていないのに「レタスとトマトとキュウリ」に分解するような補完です。
これが記録として残ると、その記録は事実ではなくなります。

そこで3層で受け止めています。

**第1層 — 指示**

「補完しないで」と1行書くだけでは足りないので、何が禁止かを具体例で示しています。
「白米とだけ書かれていたら量は不明。茶碗1杯だろうと補ってはいけない」というように。

**第2層 — 欄を絞る**

AIに見せる形から、栄養値・ブランド名・調理法の欄を**消しました**。
欄が無ければ埋めようがありません。

**第3層 — 原文照合（自動）**

AIには「原文のどの部分を根拠にしたか」を必ず返させます。
その文字列が原文に無ければ、その項目は**機械的に破棄**されます。

上の例で「レタス」が消えるのはこれです。根拠として返してきた「サラダのレタス」が
原文に存在しないため、AIが足した情報だと判定されます。

破棄した項目は画面に理由付きで表示します。黙って消すと、
AIが何をしようとしたのかが分からなくなるためです。

## 3. AIがしないこと

- **カロリー・PFCを答えない**（欄自体がありません）
- **単位を勝手に換算しない**（「たまご2個」を「100g」にはしません。何グラムか聞きます）
- **量を勝手に決めない**（書いていなければ質問します）
- **食材名を勝手に言い換えない**（「サラダチキン」を「鶏むね肉」にしません）

栄養値は食品マスタから引きます。マスタに無ければ、利用者が手で入れます。
**AIが起こすのは下書きだけで、確定するのは必ず人です。**

## 4. テスト

| 種類 | 件数 | 実行場所 |
|---|---|---|
| 単体テスト | 157件（+32） | CI・毎回 |
| 権限テスト | 95件 | CI・毎回 |

内訳の追加分:

- 中継役の署名検証 15件（上記）
- AI応答の取り込み 17件
  - 個・杯などの単位を換算せず、利用者に聞くこと
  - 栄養値・ブランド名・調理法が一切入らないこと
  - 根拠が空の応答を受け付けないこと
  - **原文に無い根拠の項目を捨てること**
  - 全角・半角のゆれでは捨てないこと

## 5. ★ あなたにお願いする設定作業

ここからは画面の操作だけです。別紙 `docs/SETUP-AI.md` に手順を書きました。

1. Google AI Studio で APIキーを取得（無料・カード不要）
2. Cloudflare のアカウント作成（無料・カード不要）
3. Worker を作り、`worker/worker.js` の中身を貼り付ける
4. キーなどを登録する
5. できたURLを GitHub に登録する

**設定が済むまで、AIのボタンは表示されません。** アプリは今までどおり動きます。
