代表の表記の選び方を直しました
========================================

apps と packages を pt-app へ貼り付け → Commit → Push。
Firestore のルールは変えていないので、コンソールでの作業はありません。


何が起きていたか
----------------------------------------

「サラダ　チキン」（全角スペース入り）のほうで登録されていました。

原因は私の設計ミスです。
依頼の代表名を「最後に書いた人の表記」で毎回上書きしていました。

    1回目「サラダチキン」    → 代表 = サラダチキン
    2回目「サラダ　チキン」  → 代表 = サラダ　チキン  ← 上書き

誰が最後に打ったかは、正しさと何の関係もありません。


どう直したか
----------------------------------------

代表名を保存しないことにしました。
表記は各契約者のぶんだけ残し、**読むときに選びます**。

選び方:

    1. いちばん多く使われた表記   … 多くの人が書く形が自然な形
    2. 同数なら短いほう           … 余分な空白や記号が入っていない
    3. それでも同じなら文字順     … 毎回同じ結果になるように

上の例なら、どちらも1回なので「短いほう」= サラダチキン が代表になります。

さらに、登録画面で表記を1タップで選び直せるようにしました。
選び方が常に正しいとは限らないので、最後は人が決められるようにしています。

ついでに、意味のない別名を作らないようにしました。
「サラダチキン」と「サラダ　チキン」は別名が無くても同じものとして
当たるので、別名に入れても何も増えません。


★ いま登録済みの「サラダ　チキン」について
----------------------------------------

すでにマスタに入っているものは、自動では直りません。

  管理者 → 食品マスタ → 「サラダ　チキン」の【編集】
  → 名前を「サラダチキン」に直して保存

過去の記録に出ている名前はそのままです（勝手に書き換えない方針のため）。
気になる場合は、その食材を消して入れ直してください。
