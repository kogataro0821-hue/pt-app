===========================================================================
【重要】 Cloudflare の作業（順番どおりにお願いします）
===========================================================================

  ★ KV を先に作ってください。先にコードを貼ると、
    KVができるまでの間「数えていない」状態になります。


  --- 作業1: 回数を数える場所を作る（5分）------------------------------

  1. https://dash.cloudflare.com を開く

  2. 左メニュー「Storage & Databases」→「KV」
     （見当たらなければ「Workers & Pages」→「KV」）

  3. 「Create a namespace」を押す

  4. 名前を   pt-ai-rate   にして作成

  5. 左メニュー「Compute (Workers)」→「pt-ai」を開く

  6. 「Settings」タブ →「Bindings」

  7. 「Add」→「KV namespace」を選び

        Variable name  :  RATE_LIMIT      ← ★ここちょうどに
        KV namespace   :  pt-ai-rate

     ⚠ 変数名は RATE_LIMIT ちょうどです。大文字・下線までこのとおりに。

  8. 「Deploy」を押す


  --- 作業2: worker.js を貼り直す（3分）--------------------------------

  1. C:\Users\user\Desktop\pt-app\worker\worker.js をメモ帳で開く
  2. Ctrl + A  →  Ctrl + C
  3. Cloudflare →「Compute (Workers)」→「pt-ai」→「Edit code」
  4. エディタの中で Ctrl + A → Delete
     ⚠ 継ぎ足さないでください。古い中身が残ると動きません
  5. Ctrl + V で貼り付け
  6. 右上の「Deploy」

  ※ GEMINI_API_KEY などの設定は消えません。別の場所に保存されています。


  --- 作業3: 確認（1分）------------------------------------------------

  ブラウザで Worker のURL（https://pt-ai.〇〇〇.workers.dev）を開く。

    "dailyLimit": "有効（1人あたり1日 50 回まで）"     ← これが出れば成功

    "dailyLimit": "⚠ 数えていません..."               ← 作業1の変数名を見直す

  ※ この画面にAPIキーは出ません。撮って送っていただいて大丈夫です。
